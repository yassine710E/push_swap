# push_swap

## Description

**push_swap** is an algorithmic project from the 42 Network.  
The objective is to sort a stack of integers using two stacks only (a and b) and a limited set of operations, while generating the lowest possible number of instructions.

The main difficulty of the project is choosing an efficient sorting strategy and optimizing each operation to reduce the total number of moves, especially when handling large input sizes.

This implementation is based on the **Chunk sorting algorithm**, a strategy commonly used to efficiently solve the push_swap problem for medium and large datasets.
